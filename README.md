# 🛒 BlinkIT Sales Analysis Dashboard

## 📌 Project Overview

This project presents a comprehensive sales analysis of the BlinkIT Grocery dataset using **Microsoft Excel**, **MySQL**, and **Power BI**. The objective is to transform raw sales data into meaningful business insights through data cleaning, SQL analysis, interactive dashboards, and data visualization.

This project demonstrates the complete Data Analyst workflow—from data preparation to business intelligence reporting.

---

## 🎯 Project Objectives

- Analyze overall sales performance.
- Identify top-selling product categories.
- Compare sales across different outlet types.
- Analyze customer ratings and item visibility.
- Evaluate the impact of outlet size and location on sales.
- Build interactive dashboards for business decision-making.
